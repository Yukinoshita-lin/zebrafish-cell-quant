中后肠 U-Net v3 训练报告（针对 v2 欠拟合的第二轮）
========================================================
背景：v2 诊断（tools_diagnose.py）显示阈值非瓶颈、0 张灾难失败、
     42.5% 样本挤在 Dice 0.4~0.6 -> 判定欠拟合，非数据问题。

v3 改动：深监督 + 权重EMA + 仿射/光度增强 + base 32 depth 4
配置：输入 ÷4（688x552），
      7.76M 参数，AdamW lr=0.002 + warmup+cosine，
      加权BCE(pos_weight=20.0) + SoftDice，300 epochs
数据：train 150 / test 40（按图划分，人工掩码 GT）

结果：
  测试集 Dice @0.5: 均值 0.8021  中位 0.8270  P10 0.6760
  最佳阈值 0.4 -> Dice 0.8029（较 @0.5 +0.0007）
  极端 4 张全图口径 Dice: 均值 0.7388
  最佳 epoch: 285（Dice 0.8021）
  v2 基线 @0.5 = 0.5798 -> v3 提升 +0.2223
  验收标准（需求 7）：Dice >= 0.85 -> 仍未达标
